# Qatar Education Monitor v0.3 — Full-Stack Platform Implementation Plan

**Summary:** Transform `qatar-edu-monitor` from a CLI-only tool into a complete full-stack web platform using `Hono` + `better-auth` (Microsoft OAuth) + `PostgreSQL`/`Drizzle ORM` + a DB-backed background AI solve worker + `TanStack Router`/`TanStack Query` + `Hono RPC` + Arabic RTL `shadcn/ui`. The platform discovers enrolled subjects and due quizzes, solves them in the background as drafts (never auto-finishing), lets the user review/edit answers, and submit an explicit human `Finish`.

**Execution Rule:** This plan is divided into 7 strictly gated phases. **No phase may begin until all build/test commands in its gate pass.** Every part includes automated tests and verification.

## Key Technical Decisions

1. **Auth & DB:** `better-auth` with Microsoft social provider (Entra ID), Drizzle adapter on PostgreSQL. Tables: `users`, `sessions`, `accounts`, `verifications` + app tables `user_lms_credentials`, `user_llm_settings`, `lms_classes`, `lms_quizzes`, `quiz_attempt_questions`, `solve_batches`, `solve_jobs`.
2. **Secrets at rest:** `AES-256-GCM` vault (`crypto-vault.ts`) for LMS cookies and per-user LLM API keys. Cookie values are never returned by any API; only names (`cookieNames`) and status. SSRF allowlist: HTTPS + `qeducation.edu.gov.qa` / `*.edu.gov.qa` only.
3. **Two-Tier `/finish/` Guardrail:** `LmsHttpClient` throws on `/student_take_quiz_assignment/finish/` for ALL callers by default. Only `submitQuizFinishExplicitly()` in `quiz-finish.service.ts` can pass a module-private `Symbol` capability. AI solver and CLI can never reach it.
4. **Background Jobs (no Redis):** PostgreSQL `solve_jobs` table claimed via `FOR UPDATE SKIP LOCKED`, partial unique index prevents duplicate active job per quiz, and a `NOT EXISTS` guard enforces **1 running job per `user_id`** (protects the single LMS session/cookie state per student) while allowing parallel jobs across different users. Per-question progress checkpointing + stale-lease reaper for crash recovery.
5. **Frontend:** Arabic-only RTL (`dir="rtl" lang="ar"`), Tailwind CSS v4 + `shadcn/ui` primitives, `hc<AppType>` typed RPC client, `TanStack Query` with smart polling (2.5s while jobs active, stops when idle), `better-auth/react` client.
