Phase 7

AI generation and local draft review

Hallili now produces structured local drafts through a provider port, validates answers against extracted question options, stores current drafts and append-only revisions, protects edits with optimistic concurrency, and exposes a polling review UI. A local draft is never represented as an LMS submission.

Supported local schemas: single/multiple choice, true/false, and bounded text. File-upload questions are not guessed; they become manual-input blockers.

Provider boundary: fake remains default. An OpenAI-compatible adapter exists behind explicit server configuration, with timeout, 429/503/auth/schema classification and transient fallback policy.

Validation: choices must be inside extracted option IDs; malformed confidence/schema responses are rejected before persistence.

Review semantics: edits are local-only, increment version, append a revision, and never implicitly write to the LMS.
