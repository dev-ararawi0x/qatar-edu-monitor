apps/web: the TanStack Start process. It owns UI/SSR now and will own the only browser-facing REST API in later phases.

apps/worker: a separate long-running Node.js process. It currently proves independent startup/shutdown and emits heartbeat logs; it exposes no HTTP business API.

packages/domain: framework-free domain primitives and errors. It may not import Drizzle, TanStack, Better Auth, LMS, or AI infrastructure.

packages/application: actor context, application errors, and narrow ports used by future use cases.

packages/contracts: Zod transport schemas, currently the shared safe API error envelope.

packages/db: reserved package boundary for Drizzle persistence introduced in Phase 2.

packages/integrations/runtime: dotenv loading, fail-closed environment parsing, secret-safe structured logging, and recursive redaction.

infra/docker/compose.yaml: local PostgreSQL 17 service with a healthcheck and named volume.

scripts/db-compose.sh: chooses Docker when usable, otherwise rootless Podman, and starts the user Podman socket when needed.

apps/web/vitest.config.ts: isolates unit tests from the TanStack/Vite production plugin pipeline.

scripts/check-architecture.mjs: static guardrails for forbidden dependency edges.

  1. 1. The browser talks only to apps/web. UI route files do not import database or integration packages.
  2. 2. Web and Worker are composition roots. They will wire concrete adapters into Application use cases rather than placing business rules in routes.
  3. 3. Application code will depend inward on Domain and outward only through narrow ports.
  4. 4. DB, LMS, AI, encryption, logging, and runtime configuration implementations remain outside Domain/Application.
  5. 5. The Worker starts independently, emits sanitized structured heartbeats, stops on SIGTERM/SIGINT, and cannot reference a final-submission capability.
Allowed

apps → application → domain; composition roots may wire adapters.

Forbidden

Domain → infrastructure, route → SQL/provider, Worker → final action.

Fail closed

Missing critical env values stop startup; LMS and remote draft writes default off.
