Branch mechanicsRenamed the temporary local hallili branch to hallili/v0.1.Git cannot create hierarchical ref hallili/v0.1 while hallili exists.No product impact; repository-only detail.
Dependency pinningPinned exact versions published at least seven days before implementation where available, including TanStack Start 1.169.5, Router 1.170.46, Vite 8.3.8, React 19.3.1, TypeScript 5.9.3, and Vitest 5.1.0.Supply-chain caution and reproducibility; docs require compatibility review but do not choose exact versions.Record final compatibility matrix in Phase 2.
PostgreSQL imageUsed postgres:17-alpine for local development.The docs require PostgreSQL but not a local image/version.Confirm production PostgreSQL major version before release hardening.
TypeScript package buildsPackage build scripts currently typecheck source rather than emit compiled package artifacts; apps consume workspace TypeScript source.Keeps the first vertical slice simple in a pnpm monorepo.Reassess before production deployment/rollback runbook.
Generated route treeTanStack Router's generated routeTree.gen.ts is intended to be committed so clean typecheck works after install.The framework generates the file; committing generated type metadata avoids typecheck ordering complexity.Regenerate after every route change; do not edit manually.
Container runtime fallbackThe database helper uses Docker when its API is accessible; otherwise it uses rootless Podman and attempts to start the user-scoped podman.socket.Docker was installed but the current user could not access its socket, while Podman was available.Document operator preference if Docker socket access is later granted.
Auth schema reconciliationBetter Auth generated text IDs and timestamp columns; generated timestamp columns were adjusted to timestamptz, while Better Auth-owned text user IDs are preserved and Hallili ownership keys are strings.The database design requires timestamptz but also requires Better Auth's generated ownership shape.Promote to an ADR if schema generation is rerun or Better Auth is upgraded.
Microsoft enablement flagAdded MICROSOFT_SIGNIN_ENABLED and MICROSOFT_ALLOW_COMMON_TENANT; sign-in is off by default and common tenant requires explicit configuration.OD-10 tenant/account eligibility is not yet evidenced, so the safe implementation must fail closed.Replace/confirm after tenant policy approval.
Credential cipher key formatENCRYPTION_KEY is accepted as base64 or hex decoding to exactly 32 bytes; key version currently defaults to 1.The specification mandates AES-256-GCM and key versioning but not secret encoding or rotation operations.Promote to operational documentation before deployment/rotation.
Fixture shapeSanitized catalog fixtures use explicit data-hallili-fixture markers so unsupported markup deterministically throws PARSER_MISMATCH.Real LMS fixture shapes cannot be assumed before authorized verification.Replace with approved representative fixtures in Phase 8.
Quota baselineFor the local implementation one accepted solve job reserves one assessment unit in a UTC calendar-month bucket with a default limit of 50.OD-17 approves reserve/finalize/release behavior but not exact metric, period, or numeric limit.Reconcile with product/operator configuration before release.
Duplicate attempt IDsA job-create request containing duplicate IDs is rejected with VALIDATION_ERROR.The contract required either rejection or deterministic deduplication; rejection is safer and explicit.Document in generated/OpenAPI contract when added.
Interactive docs assetsStatic documentation uses the Tailwind CDN and small inline vanilla JavaScript rather than importing production application code.Keeps interactive documentation decoupled from runtime code as requested.If offline docs are required, vendor a static CSS build later.
