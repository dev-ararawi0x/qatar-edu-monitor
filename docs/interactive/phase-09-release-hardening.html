Phase 9

Release hardening

Security invariants, E2E smoke checks, operational health/metrics, backup/restore evidence, benchmark baselines, and deployment rollback runbooks were added. Performance sign-off and retention remain blocked where the specification's evidence gates are unresolved.

Security suite

scripts/security-check.mjs scans Worker final-action capability, embedded secret patterns, sensitive logging shapes, tracked dotenv files, and prohibited second API applications. It is part of pnpm lint.

E2E smoke

scripts/e2e-smoke.mjs starts the built web server and verifies public health plus stable 401 envelopes for protected LMS, jobs, and metrics APIs.

Health and metrics

GET /api/v1/health checks web/database liveness. Authenticated /ops polls queue, parser, provider, draft, and revision metrics. The worker writes a local metrics snapshot.

Backup evidence

scripts/db-backup.sh and scripts/db-restore.sh wrap custom-format PostgreSQL backup/restore. A backup was restored to a clean temporary database and queried successfully.
